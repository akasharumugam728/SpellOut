A custom Wear OS Minimalized watch face that spells out the time in words, giving your smartwatch a distinctive way to display the time.

🛠️ Installation
Spellout can be installed on a compatible Wear OS smartwatch using GeminiMan WearOS Manager.

Download the Spellout APK from the Releases section.
Open GeminiMan WearOS Manager and connect your smartwatch.
Use the manager to install the APK on your watch.
Select Spellout from your watch's watch face selection menu.
